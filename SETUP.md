2. Upload `README.md`, the `assets/` folder and `.github/workflows/snake.yml` to the repository root. Keep these paths unchanged.
3. Go to **Settings → Actions → General → Workflow permissions** and select **Read and write permissions**, if available. Save.

5. If the snake fails to publish, inspect the workflow log and confirm Actions permissions and repository policies.
